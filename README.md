# Jobhuntly

> Jobhuntly is web for search job

---

## 🚀 Getting Started

### Installation
1. Clone the repository:
~~~bash
git clone https://github.com/Usa-bunny/Jobhuntly.git
cd Jobhuntly
~~~
2. Install Dependencies
```bash
npm intall
```
3. Run
```bash
npm run watch:sass
```
